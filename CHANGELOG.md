# Changelog

## [0.1.0-alpha] - 2026-07-25

### Added
- SmartReplace tool: Safe code replacement with dry-run
- DeepAnalyzer tool: Analyze code structure and complexity
- Safety validation: Risk scoring & guidance generation
- OpenAI adapter: Function calling protocol integration
- State manager: SQLite-based persistence
- Rollback capability: Restore from backups
- MockAgent: Agent compliance testing framework

### Features
- ✅ Complete end-to-end flow (agent → Snowline → execution)
- ✅ Agent compliance enforcement (3 levels: strict, normal, aggressive)
- ✅ Zero API cost testing (fully local)
- ✅ Production-ready MVP

### Known Limitations
- ⏸️ Workflows not yet implemented (Phase 2+)
- ⏸️ No web dashboard (Phase 3+)
- ⏸️ No cloud deployment helpers (Phase 3+)
